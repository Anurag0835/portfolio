# ⚡ Anurag Jain — Full-Stack Developer Portfolio

A modern, responsive, and performance-optimized personal portfolio website built with modern web technologies, showcasing full-stack projects, technical skills, work experience, hackathon achievements, and education.

Live Demo: [https://anurag-portfolio.vercel.app](https://anurag-portfolio.vercel.app) *(or your deployed Vercel URL)*

---

## 🌟 Features

- **Futuristic Bento-Grid & Glassmorphism Design**: Frosted glass cards, glowing gradient borders, and ambient light meshes.
- **Dynamic Typing Terminal Effect**: Animated role switching across full-stack specializations.
- **Dark & Light Mode**: Seamless theme toggle with state persistence via `localStorage`.
- **Categorized Technical Arsenal**: Skills matrix categorized into Frontend, Backend & Databases, Tools & Platforms.
- **Interactive Experience & Leadership Timeline**: Chronological milestones with detailed roles (Mollis AI, UptoSkills, FarmSync).
- **Featured Projects with Deep-Dive Modals**:
  - **AI News Summarizer**: Category filtering + real-time Web Speech API audio demo.
  - **E-Learning Platform (LMS)**: Architecture overview, JWT authentication, and dashboards.
  - **FarmSync Assistant**: Smart agricultural technology platform (LPBEI Project Lead).
- **Direct Resume Download**: One-click download for `Anurag_Jain_Resume.pdf`.
- **Working Contact Form**: Integrated with FormSubmit for direct email delivery to Gmail, with Web Gmail fallbacks.
- **Instant Clipboard Actions**: 1-click copy for email, phone, and text with custom floating toast notifications.

## 🛠️ Tech Stack

- **Build Tool & Dev Server**: [Vite](https://vitejs.dev/)
- **Frontend Core**: Semantic HTML5, Modern CSS3 (Custom properties, Bento Grid, Flexbox), Vanilla JavaScript (ES6+)
- **Typography & Icons**: Plus Jakarta Sans, JetBrains Mono, Custom SVG Vector Icons
- **Deployment Platform**: [Vercel](https://vercel.com/)

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (v9 or higher)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Anurag0835/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Production Build

To compile and minify the project for production:

```bash
npm run build
```

The optimized static assets will be generated in the `dist/` directory.

To preview the production build locally:
```bash
npm run preview
```

---

## 🌐 Deployment on Vercel

This repository is optimized for zero-config deployment on Vercel:

- **Framework Preset**: `Vite`
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`

Whenever changes are pushed to the `main` branch on GitHub, Vercel automatically creates a new production deployment.
